Constants
------------------------------

GBGPU defines no constants of its own (there is no ``gbgpu.utils.constants`` module).
:mod:`gbgpu.utils.utility` re-exports every name of ``lisatools.utils.constants``, whose
values come from the ``lisaconstants`` package (pinned to ``lisaconstants==2.0.2``), so
``from gbgpu.utils.utility import YRSID_SI, C_SI, G_SI, MSUN_SI, PC_SI, fstar`` gives the
LAT values. ``YRSID_SI`` is the astronomical year (``lisaconstants.ASTRONOMICAL_YEAR``).

The C++ / CUDA code reads the same values from ``cutils/lisaconstants_values.h``, a header
generated by ``python -m lisatools.utils.lisaconstants_header`` and checked against the
installed ``lisaconstants`` by ``tests/test_lisaconstants_values.py``.
